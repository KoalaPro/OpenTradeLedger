# v1.3.3 跨品牌 NAS 网页一键在线升级与零终端部署规格书

- **日期**：2026-11-25
- **目标版本**：`v1.3.3`

## 1. 背景与真实用户痛点

普通 NAS 用户可能将交易账本部署在 **极空间、绿联、飞牛 fnOS、群晖、威联通、Windows Docker** 等任意环境：
1. 极空间等家用 NAS 默认无内置终端，普通用户不会开启或使用 SSH 执行 `docker compose pull && docker compose up -d`；
2. 不同品牌 NAS 的 Docker 图形界面菜单差异大，依赖单一厂商教程通用性不足；
3. 首次安装若要求手动创建隐藏 `.env` 文件修改 `OTL_DEMO_MODE=false`，同样给零终端用户制造门槛。

## 2. 核心架构设计

### 2.1 网页内跨平台通用「一键在线升级」（OTA 热更新引擎）
- **构建与发布（`.github/workflows/release.yml`）**：
  - 每次推送 `v*.*.*` 标签时，自动构建前端静态资源并打包轻量热更新归档 `opentradeledger-ota.tar.gz`（包含 `manifest.json`、`backend/src/opentradeledger/`、`web/dist/`，体积约 `350 KB`）及 `opentradeledger-ota.sha256`；
  - 将权威 `OTA-SHA256` 摘要写入 GitHub Release 说明并上传双附件。
- **安全下载与国内加速回退（`core/self_updater.py`）**：
  - 通过官方 GitHub Release API（带自动重试）获取最新版本号与权威 `SHA-256`；
  - 下载归档时优先直连 GitHub，若国内网络直连超时则自动回退公开镜像代理，并强制比对权威 `SHA-256` 哈希（哈希不符立即丢弃，杜绝篡改风险）；
  - 解压过程执行严格路径穿越与符号链接拦截（仅允许 `manifest.json`、`backend/src/opentradeledger/**`、`web/dist/**`），原子化切换 `/app/data/.ota/active.json`。
- **免 `docker.sock` 轻量进程守护（`scripts/run_server.py`）**：
  - 主进程作为轻量守护启动 `--worker` 子进程，无需挂载高危 `/var/run/docker.sock`，亦不依赖用户在 NAS 勾选容器自动重启策略；
  - 子进程启动导入 `opentradeledger` 前自动比对基础镜像版本与 `/app/data/.ota/active.json`：当 OTA 版本更新且满足 `min_base_version` 时优先挂载 OTA 代码与静态资源；若用户日后手动更新了更高版本的底层 Docker 镜像，自动切回新镜像并清理旧 OTA 目录；
  - 升级完成后写入 `.restart_requested` 标记并优雅退出子进程，主守护在 1 秒内拉起新版本子进程，NAS 重启后因 `/app/data` 持久化依然保持最新版本。

### 2.2 首次部署彻底告别 `.env` 与终端
- 在网页中关闭「演示数据模式」开关、首次保存只读交易所 API Key 或添加盯盘目标时，后端自动持久化退出 `demo_mode`，即时衔接本地访问密码初始化；
- 更新 `SettingsPage.tsx` 与 `README.zh-CN.md`：以「一键在线升级」作为主按钮，将各品牌 NAS 图形界面重拉镜像说明与进阶终端命令收折为可选辅助指引。
