# OpenTradeLedger v1.3.1 — Public Copy-Trade Watcher & Bark Onboarding UX Spec

**Date:** 2026-11-25  
**Target Version:** `1.3.1`  
**Status:** Approved for Implementation

---

## 1. Goals & Scope

1. **Built-in Public Copy-Trade Slot & Position Watcher (`core/copy_watcher.py`)**
   - Migrate and upgrade the keyless public Binance copy-trading radar directly into `OpenTradeLedger`'s FastAPI `lifespan` as an isolated async background task (`CopyWatcherService`), eliminating external host `launchd` daemon scripts.
   - Poll enabled targets every **10 seconds** for lead portfolio slot availability (`currentCopyCount / maxCopyCount`, minimum copy amount, profit sharing rate) and every **30 seconds** (every 3 cycles) for public order/position history to infer live open positions and aggregate new trade actions.
   - **Per-Target Granular Controls**: Each watched lead trader (`CopyWatcherTarget`) independently controls `enabled`, `slot_alert` (30s urgent Bark `alarm` ring + `bnc://` deep link with 180s cooldown; resets immediately when full), and `trade_alert` (single `bell` chime on merged open/close batches; silent watermark anchor on first sight).
   - **Strict Read-Only & Keyless Guard**: `GET`-only for detail and mark price queries; strict path whitelist for Binance's two unauthenticated pagination endpoints (`/bapi/futures/v1/friendly/future/copy-trade/lead-portfolio/order-history` and `position-history`) with hard assertion forbidding any API key or authorization headers.
   - **Zero Personal Hardcodes & Demo Mode**: Default target list is `[]`. Demo Mode returns realistic sanitized demo lead traders (1 with open slots, 1 full) with inferred positions and recent orders so first-time users immediately see how the radar works.

2. **Dedicated Frontend Sub-Tab (`#/extensions/watcher`) & Step-by-Step Beginner Guides**
   - Upgrade **Modules (`ExtensionsPage`)** to 3 sub-tabs: **`公开盯盘` (`Public Radar`)** · **`跟单专账` (`Copy Ledger`)** · **`股票与代币账户` (`Equities & Tokens`)**, with an independent toggle `modules.copy_watcher` in Settings and an open-slot badge indicator.
   - Include a clear, collapsible **"如何获取带单员链接 / ID" (How to Find a Lead Trader Link / ID)** 3-step guide covering both **Binance Mobile App** (Contract -> Copy Trading -> Trader Profile -> Top-right Share -> Copy Link) and **Desktop Web** (copy `lead-details/<id>` URL or 15–22 digit ID), accepting pasted share text, full URLs, or comma-separated IDs.

3. **Bark Push Beginner Guide & Triple Anti-Footgun UX**
   - Clear inline guide in **Settings -> Notifications** (and quick setup banner in **Public Radar** when no push channel is configured) explaining how iOS users install **Bark** from the App Store, copy their URL/Key, and what events trigger alerts (open copy slots, lead trader fills, personal closed trades, background exchange sync errors).
   - **Smart Bark URL Parsing (`parse_bark_input`)**: Automatically split full pasted Bark URLs (e.g. `https://api.day.app/AbCdEfG/这里改成你自己的推送内容` or self-hosted Bark URLs) into `bark_server_url` + clean `bark_push_key` on both frontend and backend.
   - **Save-on-Test Anti-Footgun**: Clicking **"测试推送" (Test Push)** in Settings automatically persists any unsaved notification inputs in the form before dispatching the test push.

4. **Optional Outbound Proxy & v1.3.0 Walkthrough Polish**
   - Add optional `outbound_proxy_url` (HTTP / HTTPS / SOCKS5 proxy, e.g. `http://127.0.0.1:7890`) in Settings, wired into `CopyWatcherService` and exchange `httpx.AsyncClient` instances for reliable LAN/NAS connectivity.
   - `docker-compose.yml`: parameterize port `${OTL_EXTERNAL_PORT:-8012}:8012` and document `ghcr.nju.edu.cn` mirror in `README.zh-CN.md`.
   - Fix `httpx.ConnectTimeout` empty string formatting (`failed (0):`) in exchange clients and classify `failed (0)` as `NETWORK_UNREACHABLE` in `venue_health.py`.
   - Increase dark-mode modal/drawer surface & backdrop opacity in `theme.css` to prevent underlying chart bleed-through; align AI disclosure bullet count in `FeesAiPage.tsx`.
